Getting Started

DESCRIPTION
===========
  This example guides the user to :
   - configure GPIO4 as output push-pull
   - write on the GPIO4 port

  It is made of 3 steps :
  1) GPIO4 configuration in output push-pull mode to use STR73x-Eval board's
     leds

  2) Drive leds connected to the GPIO4 pins:
     - Set led connected to PIN0
     - Reset led connected to PIN0
     - Set GPIO4 LSB
     - Set GPIO4 MSB
     - Reset all GPIO4 pins
     - Set all GPIO4 pins

  3) Make a loop on all GPIO4 connected leds
     - Set  GPIO4 pins one by one in a sequence. 

COMPATIBILITY
=============
  The project is compatible with the STR730-EVAL board.
  The project is by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The application is downloaded to the internal flash.

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Build and download the example.
  4) Run the example.
