Example description

  
UART

DESCRIPTION
===========
  This example gives an example of the UART peripheral use :

  Send 'A' character from UART0 to a PC terminal program.

COMPATIBILITY
=============
  The project is compatible with the IAR STR731-SK evaluation board.
  The project is by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The application is downloaded to the flash memory.

  Configure the PC serial port/terminal application: 

   * 9600 bps
   * 8 data bit
   * parity even
   * 1 Stop bit
   * No flow control

  Jumpers:
   EXT/JLINK - the correct jumper position depends on the power source used

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Connect UART0 to your PC via a RS232 cable.
  3) Power the board.
  4) Build and download the example.
  5) Run the example.
