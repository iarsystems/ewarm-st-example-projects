## CMSIS
Some projects in this repository make use of CMSIS or CMSIS-DSP.

The latest available CMSIS version can be found at https://github.com/ARM-software/CMSIS_6.

To build CMSIS-DSP libraries in Embedded Workbench, follow this guide https://github.com/IARSystems/IAR-CMSIS-DSP.

Read these [**NOTES**](https://github.com/iarsystems/embedded-workbench-example-projects/blob/main/NOTES.md) for more information.
