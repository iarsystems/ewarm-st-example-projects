Getting Started

DESCRIPTION
===========
  This example project shows how to use IAR Embedded Workbench for ARM
  to develop code for the SR5E1-EVBE7000P board. It shows basic use of I/O,
  system initialization and timer.
  The example blinks the on-board user LED_0.

COMPATIBILITY
=============
  The example project is compatible with the SR5E1-EVBE7000P evaluation board.
  By default, the project is configured to use the I-Jet SWD interface.

CONFIGURATION
=============
  Use the default jumper and switch settings on the board.
  For more information, read the user manual of SR5E1-EVBE7000P board.

GETTING STARTED
===============
  1) Build and download the example.
  2) Run the example.
