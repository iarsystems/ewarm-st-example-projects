DESCRIPTION
===========
   This example project shows how to use the IAR Embedded Workbench for ARM to
  develop code for the STR912-SK-IAR evaluation board. It implements an usb audio
  device with one output and one input.

   The first time the device is connected to the computer, the OS (Windows) will
  load the driver for identified device. The USB Audio Device driver will be
  automatically loaded.

COMPATIBILITY
=============
  The project is compatible with the IAR-STR912-SK evaluation board.
  The project is by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The application is downloaded to the flash memory.

GETTING STARTED
===============
  1) Build and download the example.
  2) Run the example.
