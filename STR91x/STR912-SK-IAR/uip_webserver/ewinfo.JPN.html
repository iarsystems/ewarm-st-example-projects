Example description

  
uIP Webserver

DESCRIPTION
===========
   This example project shows how to use the IAR Embedded Workbench for ARM to 
  develop code for the IAR-STR912-SK evaluation board. This demo shows a webserver 
  application runing on the top of the uIP 1.0 TCP-IP stack.

  The default IP address is:
   192.168.0.100
  The physical MAC address is (defined in STR912_enet.h):
   00-ff-ff-ff-ff-ff

COMPATIBILITY
=============
   This example project is compatible with, and works as a standalone project,
  on the IAR-STR912-SK evaluation board.
   The project is by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The application is downloaded to the flash memory.

  Set the jumpers:
   POWER_SELECT	- depends on the power source
   USB_DIS	- 2-3
   RST-TRST	- OFF
   PWDW_D	- 1-2
   Jumper array J16 and J15 - 2-3 (near prototype area) when J-Trace is used

GETTING STARTED
===============
  1) Build and download the example.
  2) Run the example.
  3) Use an USB cable to connect the PC to the USB of the board
