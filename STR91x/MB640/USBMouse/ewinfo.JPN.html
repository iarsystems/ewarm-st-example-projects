Example description

  
USB Mouse

DESCRIPTION
===========
   This example project shows how to use the IAR Embedded Workbench for ARM
  to develop code for the STR910 Evaluation board (MB460). It implements
  an USB HID mouse.

  Buttons:
   Joystick - Left, Right, Up, Down mouse direction and Left mouse button
   KEY - Right mouse button

COMPATIBILITY
=============
  The USBMouse example project is compatible with STR910 Evaluation board (MB460).
  By default, the project is configured to use the J-Link JTAG interface.

CONFIGURATION
=============
   The GetingStarted application is downloaded to the Flash memory on the
  evaluation board and executed.

  Make sure that the jumpers settings are regarding STR910 Evaluation board
 (MB469) user manual.

GETTING STARTED
===============
  1) Build and download the example.
  2) Run the example.
  3) Use an USB cable to connect the evaluation board to your PC.
