Example description

  
ADC

DESCRIPTION
===========
   These projects provide short description of how to use the ADC peripheral
  and give an example how to configure the ADC in continuous mode.

   The example permits to convert the analog signal issued from a potentiometer
  (AN_TR on the IAR-STR912-SK board) and connected to the channel 5 (P4.5 pin
  126) of the ADC.

  The converted value is used to set the pulse of TIM0 which is used in PWM mode.

  You can see the PWM signal generated by the timer in the P3.0 pin (variation of
  luminosity in LED1 on the IAR-STR912-SK board).

COMPATIBILITY
=============
  The project is compatible with the IAR-STR912-SK evaluation board.
  The project is by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The applications are downloaded to the flash memory.

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Build and download the example.
  4) Run the example.
