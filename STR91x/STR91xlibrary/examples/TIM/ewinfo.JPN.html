Example description

  
TIM

DESCRIPTION
===========
   These projects provides a short description of how to use the TIM peripheral and
  gives an example how to configure the TIM0 in PWM and TIM2 in OPM mode.

  You can see the PWM signal generated by the timer in the P4.0 pin.

COMPATIBILITY
=============
  The projects are compatible with the IAR-STR912-SK evaluation board.
  The projects are by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The applications are downloaded to the flash memory.

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Select a project.
  4) Build and download the example.
  5) Run the example.
