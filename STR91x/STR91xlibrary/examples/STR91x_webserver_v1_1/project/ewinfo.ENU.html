Example description

  
uIP Webserver

DESCRIPTION
===========
   This demo shows a webserver application runing on the top of the uIP TCP-IP
  stack.

  You can ping the board, by typing in the dos command window: "ping 192.168.0.8"
COMPATIBILITY
=============
  The project is compatible with the STR912-SK-IAR evaluation board.
  The project is by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The application is downloaded to the flash memory.

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Build and download the example.
  4) Run the example.
  5) Change your PC IP address to 192.168.0.x (x different from 8).
  6) Connect your PC to the IAR-STR912-SK board using an Ethernet crossover
     cable or through a hub or switch.
  7) Type http:\\192.168.0.8 in your internet browser to load the STR91x webpage
