Example description

  
MC

DESCRIPTION
===========
   This example show how to configure the MC peripheral to generate Three
  complementary PWM signals, to insert a defined dead time value and to use the
  Tacho interface in hardware Mode. The PCLK frequency is set to 25 MHz, the MC
  is running at 11.73 KHz, the PulseU, PulseV and PulseW duty cycles are fixed
  respectively to 50%, 25% and 12.5%. The dead time is equal to 148 microsecond.
  The PWM waveform can be display in a scope.

COMPATIBILITY
=============
  The project is compatible with the IAR-STR912-SK evaluation board.
  The project is by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The application is downloaded to the flash memory.

  Connect a scope to:
  - Pin29 (P6.00/MC_UH).
  - Pin31 (P6.01/MC_UL).
  - Pin19 (P6.02/MC_VH).
  - Pin20 (P6.03/MC_VL).
  - Pin83 (P6.04/MC_WH).
  - Pin84 (P6.05/MC_WL).

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Build and download the example.
  4) Run the example.
