Example description

  
GPIO

DESCRIPTION
===========
   This example provides a short description of how to use the GPIO peripheral
  and gives a configuration sequence.

  All leds of GPIO3 are toggled in an infinite loop.

COMPATIBILITY
=============
  The project is compatible with the IAR-STR912-SK evaluation board.
  The project is by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The application is downloaded to the flash memory.

GETTING STARTED
===============
  1) Power the board.
  2) Select a project.
  3) Build and download the example.
  4) Run the example.
