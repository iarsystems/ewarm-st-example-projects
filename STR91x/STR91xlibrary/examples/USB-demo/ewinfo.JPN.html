USB Demo

DESCRIPTION
===========
   This example provides a description of how to use the USB on the STR91x
  devices. The STR91x device is enumerated as an USB Mouse, that uses the native
  PC Host USB HID driver.
  Push-buttons(connected to p7.3, p7.4, p7.5 and p7.6) mounted on the STR912-SK-IAR 
  board are used to emulate the Mouse directions.

COMPATIBILITY
=============
  The project is compatible with the IAR-STR912-SK evaluation board.
  The project is by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The application is downloaded to the flash memory.

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Build and download the example.
  4) Run the example.
  5) Use an USB cable to connect the PC to the USB of the board.
