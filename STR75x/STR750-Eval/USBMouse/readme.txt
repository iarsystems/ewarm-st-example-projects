DESCRIPTION
===========
   This example project shows how to use the IAR Embedded Workbench for ARM
  to develop code for the STR750 Evaluation board (MB469). It implements
  USB HID mouse. The joystick control up, down, left, right and left mouse
  direction, and key is the right mouse button.

  Buttons:
   Joystick - Left, Right, Up, Down mouse direction and Left mouse button
   KEY - Right mouse button

COMPATIBILITY
=============
   The USBMouse example project is compatible with the STR750 Evaluation
  board (MB469). By default, the project is configured to use the J-Link
  JTAG interface.

CONFIGURATION
=============
   The GetingStarted application is downloaded to the Flash memory on the
  evaluation board and executed.

   Make sure that the jumpers settings are regarding the STR750 Evaluation
  board (MB469) user manual.

GETTING STARTED
===============
  1) Build and download the example.
  2) Run the example.
