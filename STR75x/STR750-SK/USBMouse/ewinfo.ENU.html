Example description

  
USB Mouse

DESCRIPTION
===========
   This example project shows how to use the IAR Embedded Workbench for ARM
  to develop code for IAR STR750-SK board. It implements an USB HID mouse.

COMPATIBILITY
=============
  The project is compatible with the IAR STR750-SK board
  The project is by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
   The GetingStarted application is downloaded to the flash memory on the
  evaluation board and executed.

  Jumpers:
   PWR_SEL   - depend of power source
   VRE       - OFF
   BOOT0     - 0
   BOOT1     - 0

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Build and download the example.
  4) Run the example.
  5) Use a USB cable to connect the evaluation board to your PC.
