Example description

  
PWM

DESCRIPTION
===========
   These examples show how to configure the PWM peripheral to generate three
  complementary PWM signals, to insert a defined dead time value and to lock the
  desired parameters, how to configure the PWM peripheral to generate three
  independants PWM signals and how to synchronize the TIM0 peripheral and the
  PWM peripheral.

COMPATIBILITY
=============
   The projects are not fully compatible with the IAR STR750-SK evaluation board
  since the PWM1, PWM2 and PWM3 signals are shared with Button 3, Button 2,
  Button 1 respectively. Despite of this you can use the examples with IAR
  STR750-SK and we recommend you don't press the buttons when this example is
  running.

  The projects are by default configured to use the J-Link JTAG interface.


CONFIGURATION
=============
  The applications are downloaded to the flash memory.

  Jumpers:
   PWR_SEL   - depend of power source

  Connect the PWM pins to an oscilloscope:
  - TIM0_OC1 pin (P0.00)
  - PWM1  pin (P1.09)
  - PWM1N pin (P1.08)
  - PWM2  pin (P1.07)
  - PWM2N pin (P1.06)
  - PWM3  pin (P1.05)
  - PWM3N pin (P1.04)

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Select a project.
  4) Build and download the example.
  5) Run the example.
