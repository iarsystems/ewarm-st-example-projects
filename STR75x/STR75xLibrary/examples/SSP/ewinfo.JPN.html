Example description

  
SSP

DESCRIPTION
===========
   These examples provide descriptions of how to set a communication between two
  SSPs and performs a transfer from Master to Slave and from Slave to Master in
  Motorola frame format, how to use slave receive FIFO interrupt, how to change
  Master to slave and Slave to Master without need of any hardware changes.
  The last example shows how to use the SSP software library and an associate
  SPI EEPROM driver to communicate with an M95640 EEPROM.

COMPATIBILITY
=============
  The projects are compatible with the IAR STR750-SK board.
  The projects are by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The applications are downloaded to the flash memory.

  Jumpers:
   PWR_SEL   - depend of power source
   VRE       - Absence
   BOOT0     - 0
   BOOT1     - 0

  SSP_Example1, SSP_Example2 & SSP_Example3:

  Connect both SSP0 and SSP1 pins as following:
  - Connect SSP0_SCLK(P0.05) to SSP1_SCLK(P0.16).
  - Connect SSP0_MISO(P0.06) to SSP1_MISO(P0.17).
  - Connect SSP0_MOSI(P0.07) to SSP1_MOSI(P0.18).

  SSP_Example4:

  Connect both SSP0 and SPI EEPROM pins as following:
   - Connect SSP0_NSS(P0.04)  to SPI EEPROM chip select (pin1).
   - Connect SSP0_SCLK(P0.05) to SPI EEPROM serial clock (pin6).
   - Connect SSP0_MISO(P0.06) to SPI EEPROM serial data output (pin2).
   - Connect SSP0_MOSI(P0.07) to SPI EEPROM serial data input (pin5).
   - Connect SPI EEPROM Write Protect (pin3) to Vdd
   - Connect SPI EEPROM Hold (pin7) to Vdd
   - Connect SPI EEPROM Vcc (pin8) to Vdd
   - Connect SPI EEPROM Vss (pin4) to Vss

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Select a project.
  4) Build and download the example.
  5) Run the example.
