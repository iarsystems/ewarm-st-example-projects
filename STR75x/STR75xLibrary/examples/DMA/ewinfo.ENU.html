Example description

  
DMA

DESCRIPTION
===========
   The first example provides a description of how to use DMA Stream1 with
  SSP0_TX burst request to transfer Data from SSP0 to SSP1 in burst mode.

   The second example provides a description of how to use DMA Stream3 with ADC
  request to transfer Data from an ADC Data register to a TIM0 Output Compare
  register.

   The third example provides a description of how to use DMA Stream0 with PWM
  update request to transfer data from a constant buffer (RAM or Flash) to the
  PWM Output Compare1 register.

COMPATIBILITY
=============
  The projects are compatible with the IAR STR750-SK board.
  The projects are by default configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The applications are downloaded to the flash memory.

  Jumpers:
   PWR_SEL   - depends on the power source
   VRE       - OFF
   BOOT0     - 0
   BOOT1     - 0

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Select a project.
  4) Build and download the example.
  5) Run the example.
