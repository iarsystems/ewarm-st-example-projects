Example description

  
UART

DESCRIPTION
===========
   These examples show how to use the UART in order to communicate between the
  STR71x and a PC using RS232 protocol.

COMPATIBILITY
=============
   These examples work as standalone on the STR711/STR712 IAR boards. By default
  the project is configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The application is downloaded to the flash memory.

  Configure the PC COM port with the following settings:

   * 9600 bps
   * 8 data bit
   * no parity
   * 1 Stop_bit
   * No flow control

  Use the Jumpers RX01 and T01 to choose the UART0

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Connect a PC serial port to the UART0 and open a terminal application.
  3) Power the board.
  4) Build and download the example.
  5) Run the example.
