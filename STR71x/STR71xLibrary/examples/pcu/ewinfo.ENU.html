Example description

  
PCU

DESCRIPTION
===========
   This example highlights one of the features of the PCU which is to put
  the chip in stop mode and use the wakeup pin to resume program execution.

  This example demonstrates the following features of the PCU :
   - Initialization,
   - External wakeup line configuration,
   - Entering stop mode,
   - Exit from stop mode using a wakeup line.

COMPATIBILITY
=============
   This example works as standalone on the STR711/STR712 IAR boards. By default
  the project is configured to use the J-Link JTAG interface

CONFIGURATION
=============
  The application is downloaded to the flash memory.

  Put the Jumper Dis/Led on the position 1-2(only for STR711 IAR Board)

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Build and download the example.
  4) Run the example.
