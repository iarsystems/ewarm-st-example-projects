Example description

  
RTC

DESCRIPTION
===========
   This example demonstrates how to configure the RTC in order to generate an
  IRQ every second using the RTC second interrupt. The ISR will then clear the
  RTC interrupt and toggle the P1.8 pin.

  This example demonstrates the following features of the RTC:
   - Configure the prescaler,
   - Enable the RTC second interrupt and global interrupt,
   - Toggle P1.8  pin every sec in the IRQ handler.

COMPATIBILITY
=============
  This example works as standalone on the STR711/STR712 IAR boards. By default
 the project is configured to use the J-Link JTAG interface.

CONFIGURATION
=============
  The application is downloaded to the flash memory.

  Put the Jumper Dis/Led on the position 1-2 (only for STR711 IAR Board)

GETTING STARTED
===============
  1) Connect the J-Link.
  2) Power the board.
  3) Build and download the example.
  4) Run the example.
