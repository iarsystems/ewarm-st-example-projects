    This page allows you to get continuously the ADC2 Channel 6 analog input converted value and the board temperature. This ADC Channel is connected to the IAR-STM32F429II-SK board's potentiometer. The ADC value is updated, automatically, each second with the last converted ADC value. You could check this by changing the potentiometer position and check that the ADC value is updated, by an automatic refresh.
