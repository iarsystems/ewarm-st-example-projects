DESCRIPTION
===========
   This example project shows how to use IAR Embedded Workbench for ARM
  to develop code for a SPEAR300 board. It shows basic use of I/O, system
  initialization PLL, DDR2, VIC, MMU, RS_GPIO and timer.

   It toggles port RS_PORT bit 0-3 (J7 pin2 - pin5) 15 times per second.

COMPATIBILITY
=============
   The example project is compatible with an EVALSPEAR300 evaluation board.
  By default, the project is configured to use the J-Link JTAG interface.

CONFIGURATION
=============
   Use the default jumper and switch settings on the board. For more information,
  read the User manual for EVALSPEAR300 board.

GETTING STARTED
===============
  1) Build and download the example.
  2) Run the example.
