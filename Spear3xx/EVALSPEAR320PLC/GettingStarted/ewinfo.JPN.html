Getting started

DESCRIPTION
===========
   This example project shows how to use IAR Embedded Workbench for ARM
  to develop code for a EVALSPEAR320PLC board. It shows basic use
  of I/O, system initialization PLL, DDR2, VIC, MMU, GPIO and timer.

COMPATIBILITY
=============
   The example project is compatible with an EVALSPEAR320PLC evaluation board.
  By default, the project is configured to use J-Link JTAG interface.

CONFIGURATION
=============
   Use the default jumper and switch settings on the board. For more information,
  read the User manual for EVALSPEAR320PLC board.

GETTING STARTED
===============
  1) Build and download the example.
  2) Run the example.
