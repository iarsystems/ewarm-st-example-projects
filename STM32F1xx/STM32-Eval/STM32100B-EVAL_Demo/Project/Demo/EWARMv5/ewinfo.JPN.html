Example description

  
DESCRIPTION
===========
   This demo project shows how to use the IAR Embedded Workbench for ARM to
  develop code for the STM32100B-EVAL board. It is a demonstration firmware
  which you can use to evaluate the capabilities of the microcontroller and
  the on-board peripherals.

  STM32F100B_EVAL_Demo Release Notes

COMPATIBILITY
=============
   The STM32F100B_EVAL_Demo project is compatible with STMicroelectronics
  STM32100B-EVAL board. By default, the project is configured to use the
  J-Link JTAG/SWD interface.

CONFIGURATION
=============
   The STM32F100B_EVAL_Demo is downloaded to the Embedded Flash memory
  on the evaluation board and executed.

  Note! The STM32100B-EVAL board comes with a MicroSD card memory
  preprogrammed with audio and image resources used by the demonstration.
  However you can load your own image (*.bmp) and audio (*.wav) files in
  the "USER" directory, providing that these file formats are supported by
  the demonstration!

  You can find the original files in folder:

  STM32-Eval\STM32100B-EVAL_Demo\project\Demo\Binary\Media

  You can find more information at http://www.st.com

GETTING STARTED
===============
  1) Build and download the example.
  2) Run the example.
